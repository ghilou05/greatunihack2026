### dea:

A tool where you upload pdfs and slides and an LLM will make a custom lesson that it will deliver using elevenlabs.

Features:

- Custom pdf viewer, so LLM can highlight things in PDF, overwrite on PDF, and scroll through PDF
- LLM(s), to deliver lesson
- Interactivity, so user can ask questions mid lesson
- User should be able to speak to it, and LLM should use TTS to speak back to us
- Transcription of what the LLM is saying

Bonus features:

- Account functionality
- Saving lessons, lesson history etc,
- study streaks and stuff
- Visualization

Tech stack:

- NextJS for front end
- FastAPI for backend
- Supabase for database (post-MVP; local disk for hackathon)
